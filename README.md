## 📂 Diretórios por Linguagem

- 📁 `c/`: Fundamentos da programação estruturada e controle de memória.
- 📁 `java/`: Paradigma orientado a objetos, tipagem forte e classes.
- 📁 `python/`: Scripts de prototipagem rápida e análise de dados.
- 📁 `js/` & `html/`: Desenvolvimento frontend básico para web.
